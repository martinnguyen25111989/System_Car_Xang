# Hệ thống ô tô xăng

Khóa học nhìn một chiếc xe xăng như một hệ thống, kèm sơ đồ 2D và mô hình 3D giản lược.

```powershell
cd web
npm install
npm run dev
```

Mở `http://127.0.0.1:5173`. Lesson 01 đang mở. Các bài sau mở khi học tới.
